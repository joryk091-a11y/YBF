# YBF - Yemen Booking Flight

واجهة ويب عربية لحجز الرحلات، مبنية بـ React + Vite + Tailwind.

## التقنيات
- React 19
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## التشغيل
```bash
npm install
npm run dev
```

## أوامر مفيدة
```bash
npm run lint
npm run build
npm run preview
```

## صفحات الواجهة الحالية
- `/` الصفحة الرئيسية
- `/search` صفحة البحث والنتائج
- `/travelers` إدخال بيانات المسافرين واختيار المقاعد
- `/payment` صفحة الدفع
- `/login` تسجيل الدخول
- `/forgot-password` نسيت كلمة المرور
- `/register` إنشاء حساب
